# backlog.md — 意図的先送り課題一覧

本ドキュメントは、各マイルストーンや Phase の実装過程で**意図的に先送りを決定した技術的課題や負債**を集約・追跡するものです。
コードレビュー時や完了条件の充足時に生じた課題は、隠蔽せずに必ずここへ追記します ([AGENTS.md](../../AGENTS.md) 完了条件)。

マイルストーンの計画策定時や次のタスクを決定する際には、必ず本ドキュメントを確認してください。

---

## 認証・ユーザ管理

| 課題 | 出所 | 再検討のトリガ |
| --- | --- | --- |
| セルフホスト向け登録制限（クローズド運用・新規登録無効化フラグ・招待制・管理者/CLI ユーザー作成） | M0 Phase 0 要件確定 | M3（認証・ユーザ管理）完了後、実運用（公開レンタルサーバ等への配置）を開始する段階 |
