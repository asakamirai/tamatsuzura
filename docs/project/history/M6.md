# M6 完了記録: PWA / オフライン対応と同期

- **完了日**: 2026-11-22
- **対象マイルストーン**: M6（[milestones.md](../milestones.md)）

## 達成内容

1. **Phase 1: Web App Manifest・Service Worker・ビルド/静的配信統合** (`f320807`)
   - `src/client/web/manifest.webmanifest` およびアプリアイコン 3 種（`icons/icon.svg`, `icons/icon-192.png`, `icons/icon-512.png`、`any` / `maskable` 分離）を整備し、`index.html` へ PWA メタタグ・リンクを統合。
   - `src/client/web/sw.js` を実装し、`scripts/build-wasm.sh` でアプリシェル全アセットの決定論的 SHA-256 ハッシュとプリキャッシュリスト（13 エントリ）を単一ソース注入するビルドパイプラインを構築。
   - プリキャッシュ時の `{ cache: "no-cache" }` 再検証、`/api/*`・`sw.js` キャッシュ除外、`navigate` の `text/html` Content-Type ガード、`activate` での旧キャッシュ自動削除を実装。
   - `TamaTsuzura.Server.Static` へ `.webmanifest` (`application/manifest+json; charset=utf-8`) および `Cache-Control: no-cache` を追加し、`StaticSpec.hs` と `docs/DEPLOY.md`・`docs/MANUAL_TESTS.md`（MT-3 / MT-8）を同期更新。
2. **Phase 2: IndexedDB オフライン文書キャッシュ・未同期保存キュー・オンライン復帰自動同期と競合退避通知 UI**
   - 新規コアモジュール `TamaTsuzura.Client.OfflineSync` を追加し、`CachedDocument`・`PendingSyncSave`・`SyncConflict`・`NetworkStatus`・`SyncStatus`・差し替え可能な `OfflineStore` 抽象および純粋ロジック（`baseRevision` 保持キュー集約・ローカルキャッシュフィルタ・競合/ネットワークエラー判定・別文書救出リクエスト生成）を実装。
   - `src/client/web/browser-bridge.js` の IndexedDB スキーマを v2 へ拡張（`cached_docs`, `pending_saves`, `sync_conflicts` ストア追加、共通 `openTamatsuzuraDb()` で接続共有）し、`window` の `online`/`offline` イベント監視ブリッジ (`__tamatsuzuraOffline`) を実装。
   - `TamaTsuzura.Client.App`・`View`・`I18n`・`styles.css` へオフライン時のキャッシュ閲覧・オフライン保存キュー投入・オンライン復帰時の `base_revision` 付き自動同期・HTTP 409 / 404 時の安全競合退避（サーバ非上書き）とモバイル対応の同期状態インジケータ／競合退避バナー（別文書として保存・エディタ反映・破棄）を統合。
   - すべてのオフラインストアレコードへ `ownerId` を必須保持し、マルチユーザー間のキャッシュ・未同期キュー・競合退避を厳格分離。
   - クライアント自動テストおよび手動検証手順書（[MANUAL_TESTS.md](../../MANUAL_TESTS.md) MT-9）を追加。
