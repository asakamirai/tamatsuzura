## 達成内容

1. **Phase 1: 純粋 3-way マージエンジン・任意 2 リビジョン比較 API・OpenAPI v0.5.0** (`6f2777c`)
   - `src/common/src/TamaTsuzura/Common/Merge.hs` へ完全純粋な diff3 ベース 3-way マージエンジン（`splitLinesPreserveNewlines`, `mergeThreeWay`, `renderMergedText`, `resolveMergeOutcome`, `resolveConflictBlock`）を実装。既存の Myers 差分 (`TamaTsuzura.Common.Diff`) と改行保持行トークンを活用し、片側変更・同一収束変更の自動統合と競合ブロック抽出を実現。
   - `TamaTsuzura.Common.Revision` へ `RevisionCompareResponse` DTO を追加し、`src/common/test/Spec.hs` で境界条件ユニットテストおよび `genDiffText` 多行 QuickCheck プロパティ（構造不変条件・恒等/片側/収束/解決則）を検証。
   - `GET /api/documents/{id}/revisions/compare?from={r1}&to={r2}` をサーバ（`Storage.Revision`, `Api`, `App`）へ実装し、単一読み取りトランザクション内での 2 版再構成・ハッシュ検証・所有者分離・パラメータ検証を統合。`docs/api/openapi.yaml` を v0.5.0 へ同期更新。
2. **Phase 2: クライアント任意 2 リビジョン比較 UI および 3-way マージ手動解決 UI**
   - `TamaTsuzura.Client.Api` へ `buildCompareRevisionsRequest` / `compareDocumentRevisions` を追加。
   - 編集履歴パネルへ **2版比較** タブ（`RevTabCompare`）を追加し、比較元/比較先リビジョン選択・タイトル/形式変更バッジ・本文 unified diff 表示をモバイル対応で統合。
   - 競合退避バナーへ **3-way マージで解決** を追加し、共通祖先 (`BASE`)・サーバ最新版 (`SERVER`)・ローカル退避 (`LOCAL`) から `mergeThreeWay` を実行するモバイル対応 3-way マージ解決モーダル（一括選択、競合ブロックごとの 5 種採用方針、未解決ガード、`base_revision` 付きマージ保存）を実装。
   - クライアント自動テストおよび手動検証手順書（[MANUAL_TESTS.md](../../MANUAL_TESTS.md) MT-9 / MT-10）を同期更新。
