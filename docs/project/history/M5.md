# M5 完了記録: Haskell 拡張機構 (MVP: 同梱拡張)

- **完了日**: 2026-11-22
- **対象マイルストーン**: M5（[milestones.md](../milestones.md)）

## 達成内容

1. **Phase 1: `src/extension-api/` 公開契約拡張と `src/extensions/` 同梱サンプル拡張群の実装** (`83e2599`)
   - `TamaTsuzura.ExtensionApi` へ純粋かつ将来の外部 Wasm / Web Worker 分離に耐えるシリアライズ可能な契約型（`ExtensionVersion`, `ExtensionCategory`, `CommandId`, `CommandName`, `ExtensionContext`, `ExtensionResult`, `ExtensionError`, `ExtensionCommand`, `ExtensionCommandInfo`, `toExtensionCommandInfo`）およびレジストリ不変条件検証（`validateExtensionRegistry`）を追加。
   - `src/extensions/` へ 3 種の同梱純粋 Haskell 拡張を実装し、`TamaTsuzura.Extensions.Internal` で CRLF→LF 正規化・末尾改行保持ヘルパを共通化:
     - `TrimTrailingSpaces`（既定有効）: `trim`（行末空白除去）、`normalize-blank-lines`（連続空行整理）
     - `MarkdownFormatter`（既定有効・Markdown 専用）: `format-markdown`（見出し・箇条書き統一、フェンスドコードブロック・水平区切り線・インラインバックティック保護）、`insert-toc`（冪等な目次生成・更新、未閉鎖マーカー/コード内マーカー保護）
     - `TextTransform`（オプトイン既定無効）: `sort-lines`（行昇順ソート）、`dedupe-lines`（重複行除去）、`normalize-fullwidth-alnum`（全角英数半角統一）
   - `hspec` + `QuickCheck` でレジストリ検証・フォーマット制約・冪等性・構造不変条件を検証。
2. **Phase 2: Miso クライアントへの同梱拡張レジストリ・有効化/設定 UI・拡張コマンド実行基盤の統合**
   - 結線層 `TamaTsuzura.Client.ExtensionRegistry` から `allBundledExtensions` を供給し、`client-core` が具体実装へ一切依存しないパッケージ境界を維持。
   - `TamaTsuzura.Client.App`・`View`・`I18n`・`styles.css` へモバイルファーストの **拡張機能管理** パネル（ツールバー **拡張機能** トグル、編集履歴パネルとの相互排他、CodeMirror 6 DOM 破棄回避、拡張ごとの有効/無効トグル、カテゴリ/バージョン/`Markdown 専用` バッジ、コマンド実行ボタン）およびステータスバーの有効拡張クイック実行バーを統合。
   - 無効拡張・Markdown 専用コマンドのテキスト文書実行・ゴミ箱内文書・保存/削除/リビジョン復元中に対する安全ガードと、文書切替/作成/削除/タブ切替/401 失効時の状態リセットを実装。
   - クライアント単体/MVU テスト（65 件）、手動検証手順書（[MANUAL_TESTS.md](../../MANUAL_TESTS.md) MT-3 / MT-7）、および先送り課題（[backlog.md](../backlog.md): 拡張有効状態のユーザー別永続化）を同期更新。
