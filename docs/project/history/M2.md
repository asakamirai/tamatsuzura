# M2 完了記録: MVP クライアント (モバイルファースト最小エディタ UI)

- **完了日**: 2026-11-20
- **対象マイルストーン**: M2（[milestones.md](../milestones.md)）

## 達成内容

1. **Phase 1: Miso + GHC Wasm クライアント骨格・最小 JSFFI グルーおよび M1 REST API 通信クライアント基盤の実装** (`bbaf652`)
   - `tamatsuzura-client` を `client-core` 内部サブライブラリ（`tamatsuzura-common` / `tamatsuzura-extension-api` のみ依存）＋結線層（`ExtensionRegistry`）＋Wasm Reactor エントリポイント（`app/Main.hs`）へ分離し、拡張具体実装への誤参照をコンパイル時に遮断。
   - 薄い JSFFI グルー（`TamaTsuzura.Client.Ffi`）、差し替え可能な `HttpTransport` 抽象と M1 全 10 エンドポイント対応クライアント（`TamaTsuzura.Client.Api`）、ゼロ依存 WASI preview1 シム（`src/client/web/wasi-shim.js`）、`scripts/build-wasm.sh` による Wasm インポート検証・`dist/web/` バンドル生成、および Warp 静的アセット配信（`TamaTsuzura.Server.Static`）を実装。
2. **Phase 2: CodeMirror 6 統合とモバイルファースト日本語 UI の実装** (`a6cb1a1`)
   - CodeMirror 6 を薄い JSFFI + Custom Element (`<tt-codemirror-editor>`) として統合（`src/client/web/editor-entry.js` + `TamaTsuzura.Client.EditorBridge`）。編集/分割/プレビュー切替時も DOM 破棄を避けて Undo 履歴とカーソル位置を保持。
   - 純粋 Haskell Markdown パーサ・URL サニタイザ・Miso レンダラ（`TamaTsuzura.Client.Markdown`）と日本語メッセージカタログ分離（`TamaTsuzura.Client.I18n`）を実装。
   - モバイル単一ペイン / PC 2 ペインのレスポンシブ UI（文書一覧・検索・タグ/フォルダフィルタ・新規作成・編集・明示的保存 `Ctrl+S`・未保存変更ガード・エディタ内検索/置換・ゴミ箱移動/復元/完全削除）を実装。
3. **Phase 3: IndexedDB 未保存ドラフト自動退避・復元および Markdown/テキストのエクスポート/インポート実装と疎通検証**
   - 薄いブラウザブリッジ（`src/client/web/browser-bridge.js`）と `TamaTsuzura.Client.DraftStorage` を実装。編集中の未保存ドラフトを 400ms デバウンス＋`pagehide` / `visibilitychange` / `beforeunload` 即時フラッシュで IndexedDB へ自動退避し、明示的保存・破棄・ゴミ箱移動・完全削除時に自動クリーンアップ（保存中追記は新 `updatedAt` で再退避）。
   - 再読み込み時の最新未保存ドラフト自動復元、一覧の「ドラフトあり」バッジ、サーバ側更新済み (`baseUpdatedAt` 不一致) / ゴミ箱内文書の競合保護バナー、および 404 削除済み文書の孤立ドラフト救出フローを実装。
   - `TamaTsuzura.Client.FileTransfer` を実装し、OS 安全ファイル名サニタイズ付き Markdown (`.md`) / プレーンテキスト (`.txt`) エクスポート、および UTF-8 検証・5 MiB 上限チェック・BOM 除去・拡張子からの形式/タイトル自動推論付きインポートを実装。
   - `TamaTsuzura.Client` テストスイート（`hspec` + `QuickCheck` 全 49 件）および手動検証手順（[MANUAL_TESTS.md](../../MANUAL_TESTS.md) MT-3〜MT-5）を整備。
