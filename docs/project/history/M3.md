# M3 完了記録: 認証・ユーザ管理 (CGI 互換 SQLite セッション)

- **完了日**: 2026-11-20
- **対象マイルストーン**: M3（[milestones.md](../milestones.md)）

## 達成内容

1. **Phase 1: 認証ドメイン型・パスワードハッシュ・SQLite ユーザー/セッション永続化および OpenAPI 仕様の拡張** (`33570c7`)
   - `TamaTsuzura.Common.Auth` に `UserId` / `Username`（ASCII 小文字正規化）/ `DisplayName` / `Password`（`Show` 伏せ字・`ToText` 非公開）/ `CsrfToken`（定数時間比較）および `UserProfile` / `RegisterRequest` / `LoginRequest` / `AuthSessionResponse` DTO を実装。
   - `TamaTsuzura.Server.Auth.Crypto` に Argon2id PHC ハッシュ・検証、256-bit セッション・CSRF トークン生成および SHA-256 トークンハッシュを実装。
   - `TamaTsuzura.Server.Storage.Schema`（スキーマ v3: `users`, `sessions`, `documents.owner_id`）および `TamaTsuzura.Server.Storage.Auth`（WAL 読み取り非ブロック検索・所有者スコープ文書操作）を実装し、[docs/api/openapi.yaml](../../api/openapi.yaml) を v0.3.0 へ同期。
2. **Phase 2: 登録・ログイン・ログアウト API、Cookie セッション認証ミドルウェア、CSRF 対策および文書所有者分離の実装（CGI / Warp 両検証）** (`548467f`)
   - `TamaTsuzura.Server.Auth.Cookie`・`TamaTsuzura.Server.Auth.Middleware` を実装し、`HttpOnly; SameSite=Lax; Path=/`（HTTPS 時 `Secure`）Cookie 発行・失効、`X-CSRF-Token` 定数時間照合、`Origin` / `Referer` / `Sec-Fetch-Site` 検証、`Cache-Control: no-store` 付与、および将来のクローズド運用に向けた `RegistrationPolicy` 設定分離を構築。
   - `/api/auth/{register,login,logout,me}` エンドポイントと全 `/api/documents`・`/api/tags`・`/api/folders` の所有者分離（他ユーザー文書へのアクセスは存在秘匿のため `404 Not Found`）を実装し、Warp スタンドアロンおよび CGI/1.1 双方の統合テストで検証。
3. **Phase 3: Miso クライアントへの認証画面（新規登録・ログイン・ログアウト・401 連携）統合と疎通検証**
   - `TamaTsuzura.Client.Api` へ認証 API 4 種（`registerUser` / `loginUser` / `logoutUser` / `getCurrentUser`）と `isUnauthorizedError` を追加し、全状態変更 API で `CsrfToken`（`X-CSRF-Token` ヘッダ）の付与を型レベルで必須化。
   - `TamaTsuzura.Client.App`・`View`・`I18n`・`styles.css` へモバイルファースト日本語認証画面（起動時 `/api/auth/me` 確認、ログイン/新規登録タブ、送信前バリデーション、認証済みヘッダのユーザーバッジとログアウト、未保存変更あり時のログアウト確認モーダル）を統合。
   - 認証済み操作中の HTTP 401 受信時にワークスペース状態と CodeMirror 6 を即時クリアしてログイン画面へ戻す自動失効連携（ローカル IndexedDB ドラフトは保持して再ログイン後に復元可能）と、セッション世代番号 (`authSessionSeq`) による旧セッション遅延応答の遮断を実装。
   - `TamaTsuzura.Client.DraftStorage` の `StoredDraft` へ `ownerId :: Maybe UserId` を追加し、同一ブラウザ上の別ユーザー切替時および M2 レガシードラフトに対する厳格な所有者分離を実現。
   - クライアントテスト（`hspec` + `QuickCheck` 全 56 件）および手動検証手順書（[MANUAL_TESTS.md](../../MANUAL_TESTS.md) MT-1 / MT-3〜MT-5）を同期更新。
