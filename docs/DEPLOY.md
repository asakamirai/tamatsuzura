# DEPLOY.md — デプロイメントガイド

本ドキュメントは、本エディタシステムの本番・検証環境へのデプロイ手順およびアーキテクチャ概要を定めます。

---

## 1. デプロイ形態

システムは以下の 2 つの形態でのデプロイをサポートする設計とします。

1. **スタンドアロン Docker コンテナ**:
   - Warp HTTP サーバと静的アセットを同梱したコンテナ。リバースプロキシ (Nginx / Cloudflare 等) の背後に配置。
2. **CGI / 静的配信環境**:
   - C言語互換 CGI として動作可能なバイナリと、Web サーバから配信される静的フロントエンドアセット (HTML/JS/Wasm)。

---

## 2. デプロイ後の手動検証

デプロイ完了後は、必ず [MANUAL_TESTS.md](./MANUAL_TESTS.md) に基づき、最低限 MT-1 (サインインと文書保存) の検証を実施してください。
検証結果は `MANUAL_TESTS.md` の実施記録テーブルに追記します。
